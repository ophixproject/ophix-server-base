The Ophix Project was designed by humans, for humans.

Ophix was built with the assistance of Claude Code by Anthropic. All critical code has been reviewed by humans prior to release, and humans remain central to the ongoing architecture, design, and development work.

We believe in being transparent about how we build software. AI assistance accelerates development and helps us explore ideas quickly — but the decisions, the architecture, the testing, and the judgement remain ours.
